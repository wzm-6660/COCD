# 数据集说明

本研究在三个具有代表性的数据集上进行了评估：

1. **ASSISTments09**：[1]  
   该数据集来自美国ASSISTments在线学习平台，涵盖了2009至2010学年学生与数学题目的交互行为，数据集的主要目的是分析学生的数学学习过程与行为模式。

2. **MAT2016**：[2]  
   该数据集收集于自适应地理测试环境，模拟了线下教学场景，反映了学生在地理知识点上的动态掌握情况。

3. **EdNet-1**：[3]  
   数据集源自韩国Santa智能辅导平台，包含超过78万名学生的交互记录，全面记录了学生在大规模在线教育环境下的知识学习过程。

`data` 文件夹中包含了数据集的原始数据以及处理后的数据，供进一步分析使用。
